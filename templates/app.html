nullhost apps & clients

official standalone client applications for vintage nokia symbian devices and windows desktop. direct, lightweight, and built to upload without friction.

nokia & symbian mobile

belle fp2 · symbian^3 · s60 · s40 · java me

official standalone mobile application (v1.9.5). runs natively on nokia 808 pureview (belle fp2), nokia n8, e7, c7, and series 60 devices via nokia's built-in rom java runtime. 100% dependency-free: zero python, zero qt, zero setup required.

  • in-app direct text paste creator to upload snippets directly
  • clean in-app text viewer with instant back navigation
  • automatic lightweight update checker (uses < 0.2 kb data)
  • clean 1-click photo and file selection with case-insensitive t9 filter
  • byte-accurate upload progress with transfer speed and eta
  • in-app image viewer to view hosted photos directly on device
  • photo dimensions & preview before upload with 1080p fast option
  • direct camera photo picker & storage explorer
  • find & retrieve files by 8-character item code or custom link
  • direct symbian download manager integration with password support
  • persistent account id & settings storage (rms)
  • live on-screen qr code generation for instant scanning
  • instant mobile upload without turnstile or auth errors

windows desktop

windows xp · 7 · 10 · 11 (.net 4.5+)

native windows client built in c#/.net. context menu explorer integration, automatic clipboard copy, desktop toast notifications, and fast chunked uploads.

  • official embedded nullhost icon resource
  • right-click explorer context menu upload integration
  • automatic update check on open or upload with direct 1-click update
  • instant url and raw link copy to clipboard
  • desktop progress and upload completion toast notifications
  • direct file slicing for massive multi-gigabyte uploads
