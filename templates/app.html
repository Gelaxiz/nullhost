nullhost apps & clients

native client applications for desktop, vintage Nokia Symbian, and Java-capable mobile devices.

Windows Desktop

Built with .NET for maximum compatibility. Runs on Windows XP, 7, 10, and 11. Context menu integration, clipboard copy, and background tray upload.

  • Official embedded Nullhost logo
  • Right-click Explorer upload
  • System tray notifications
  • Instant clipboard copy

Symbian ^3 (Belle FP2)

Dedicated installation package (.SISX) for Nokia Belle FP2 (Nokia 808 PureView, 701, 700, 603) and Symbian^3 / Anna (N8, E7, C7). Includes authentic Nullhost logo and Belle FP2 device compatibility.

  • Official embedded Nullhost logo
  • Belle FP2 bottom toolbar & sliding touch sheets
  • In-app & system drive file picker (C:, E:, F:)
  • Photo gallery integration & HMAC uploads

Series 60 (Keypad)

Dedicated installation package (.SIS) for non-touch S60 3rd & 5th Edition keypad phones (Nokia E52, E72, E71, C5, N95, N82, E5) with hardware D-Pad and softkeys.

  • Official embedded Nullhost logo
  • Full 5-way D-Pad tab navigation
  • Hardware CBA softkeys (Options / Back)
  • Drive explorer & photo gallery

Universal Mobile (.JAR)

Universal standalone MIDlet for any phone supporting Java (MIDP 2.0 / CLDC 1.1 + JSR-75). Runs directly on Nokia's ROM JVM with zero dependencies.

  • Official embedded Nullhost logo
  • Zero external dependencies
  • JSR-75 filesystem explorer (C:, E:, F:)
  • Adaptive touch & keypad UI

Symbian C++ Source

Complete pure native C++ source code (Avkon, CActive HTTP, RFs, Crypto, MMP, BLD.INF, PKG) for developers compiling native binaries in Carbide.c++ or Symbian SDK.

  • 100% Native Symbian C++ (Zero Qt, Zero WRT)
  • Belle FP2 bottom toolbar & touch sheets
  • S60 3rd/5th Edition CBA softkeys & keypad
  • Includes official icon assets & build scripts
