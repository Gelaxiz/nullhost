nullhost apps & clients

native client applications for desktop, vintage Nokia Symbian, and Java-capable mobile devices.

Windows Desktop

Built with .NET for maximum compatibility. Runs on Windows XP, 7, 10, and 11. Context menu integration, clipboard copy, and background tray upload.

  • Official embedded Nullhost logo
  • Right-click Explorer upload
  • System tray notifications
  • Instant clipboard copy

Symbian & Mobile Devices

Zero-dependency standalone client for Nokia Symbian Belle FP2 (Nokia 808 PureView, 701, 700, 603), Symbian^3 / Anna (N8, E7, C7), S60 keypad devices, and Series 40. Features official Nullhost logo, native filesystem browsing (C:, E:, F:), HMAC authentication, and photo gallery integration. Runs directly on Nokia's ROM JVM—zero Python runtime needed.

  • Official embedded Nullhost logo
  • Touch & D-Pad keypad navigation
  • JSR-75 native filesystem explorer (C:, E:, F:)
  • Zero Python / zero external dependencies

Symbian C++ Source

Complete pure native C++ source code (Avkon, CActive HTTP, RFs, Crypto, MMP, BLD.INF, PKG) for developers compiling native SISX binaries using Nokia Carbide.c++ or the Symbian SDK.

  • 100% Native Symbian C++ (Zero Qt, Zero WRT)
  • Belle FP2 bottom toolbar & touch sheets
  • S60 3rd/5th Edition CBA softkeys & keypad
  • Includes official icon assets & build scripts
